# typex2-recomp 0.7.5

adb downloads again in the launcher.

What's new:

- **adb downloads again on Windows and macOS.** Google replaced its Android platform tools
  37.0.3 downloads with rebuilt files under the same names, so *Settings → Tools* refused
  them with "its checksum differs". The launcher now expects the new files. If Google
  replaces a file again, the launcher checks the download against the checksum Google
  publishes for it instead of refusing it.

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Then download adb again** under *Settings → Tools* if it failed before. The games
   themselves didn't change; if the launcher still marks one *Rebuild needed*, press *Rebuild*.
3. **Android:** nothing changed in the app, the game packs or the RetroArch core.

No game files are included: you need your own copy of each game.
