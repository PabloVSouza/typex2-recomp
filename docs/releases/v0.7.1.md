# typex2-recomp 0.7.1

A smoother RetroArch core, Gouketsuji at full speed in RetroArch, and a fix for KOF 2002 UM
sometimes hanging at boot.

What's new:

- **Gouketsuji Ichizoku Matsuri Senzo Kuyou runs at 60 fps in RetroArch** on the test tablet,
  effects and all (it dropped to about 46 in fights). It now renders at its own resolution by
  default, which looks the same and costs the GPU much less; the render scale setting still
  changes it.
- **RetroArch core: more headroom for every game.** The core now prepares each frame while
  RetroArch waits for the screen and the audio, as the Android app does, instead of after.
- **KOF 2002 Unlimited Match no longer hangs at boot** on the "server authentication" screen,
  which happened about one start in eight. The NESiCAxLive steps at boot take under a second,
  with nothing to press.

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Rebuild your games.** Games are compiled on your computer, so the fixes reach them only
   when they're built again. The launcher marks the games an older version built as
   *Rebuild needed*: press *Rebuild* on each.
3. **Android:** install `typex2-android.apk` over the old app, then export the **game packs**
   again (or the **RetroArch core**, then reinstall it in RetroArch: *Load Core → Install or
   Restore a Core*) and use *Send to device*.

No game files are included: you need your own copy of each game.
