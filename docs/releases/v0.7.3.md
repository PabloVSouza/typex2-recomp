## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Rebuild your games.** Games are compiled on your computer, so the fixes reach them only
   when they're built again. The launcher marks the games an older version built as
   *Rebuild needed*: press *Rebuild* on each.
3. **Android:** install `typex2-android.apk` over the old app, then export the **game packs**
   again (or the **RetroArch core**, then reinstall it in RetroArch: *Load Core → Install or
   Restore a Core*) and use *Send to device*.

No game files are included: you need your own copy of each game.
