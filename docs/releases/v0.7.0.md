# typex2-recomp 0.7.0

Two new games, The King of Fighters 2002 Unlimited Match and Gouketsuji Ichizoku Matsuri Senzo
Kuyou, and a RetroArch core with every setting of the Android app, kept per game.

What's new:

- **The King of Fighters 2002 Unlimited Match** (NESiCAxLive). Plays on the Mac; fights run at
  60 fps on the test tablet, in the app and in RetroArch. The project stands in for the
  NESiCAxLive service and the card reader (offline, no card), so rankings are off.
- **Gouketsuji Ichizoku Matsuri Senzo Kuyou** (NESiCAxLive). Plays on the Mac; fights run at
  60 fps in the Android app. In RetroArch it stays below 60 for now: play it in the app.
  - Both games have been tested with scripted input only so far. Reports are very welcome.
- **RetroArch core: the app's settings, per game.** Core Options now has the renderer, render
  scale, FPS counter, button layout, touch pad and touch buttons. Each game keeps its own,
  saved as you change them (RetroArch 1.15 or later).
- **Touch pad in RetroArch**, out to the screen's edges, sideways and upright. Turn
  RetroArch's own overlay off to use it.
- **Choose the touch buttons:** this project's layout, Neo Geo (A B C D in a row) or your own.
  In KOF, A and C now sit over B and D.
- **Fixes:** KOF '98 UM's black sprites with OpenGL ES; a Vulkan synchronisation gap that may
  cause the missing effects on Windows with NVIDIA
  ([#7](https://github.com/PabloVSouza/typex2-recomp/issues/7)); Japanese text in the new
  games; movies that ended at once; file names in any case on Android and Linux.

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Rebuild your games.** Games are compiled on your computer, so the fixes reach them only
   when they're built again. The launcher marks the games an older version built as
   *Rebuild needed*: press *Rebuild* on each.
3. **Android:** install `typex2-android.apk` over the old app, then export the **game packs**
   again (or the **RetroArch core**, then reinstall it in RetroArch: *Load Core → Install or
   Restore a Core*) and use *Send to device*.

No game files are included: you need your own copy of each game.
