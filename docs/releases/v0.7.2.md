# typex2-recomp 0.7.2

The 8-button stick layouts now give the same buttons as RetroArch, and the Android app no longer
loses a game's settings.

What's new:

- **8-button stick layouts match RetroArch.** In the launcher, the Android app and the RetroArch
  core's *8-button stick* option, each button now does what it does in RetroArch with the game's
  default layout, combinations included:
  - KOF games: L1 / Square / L2 / Cross are A / C / B / D; Triangle, R1 and Circle are C+D,
    B+C+D and A+B.
  - BlazBlue and Samurai Shodown: R1 is A+B+C and Circle is A+B.
  - SSF4: L1 / L2 press all three punches / kicks, the single punches and kicks on the rest of
    each row.
  - Gouketsuji gets the KOF arrangement, punches over kicks.
  - Games you had set to the 8-button layout need it picked again in their settings.
- **Android app: settings no longer lost.** The app now reads each game's `x2.env` whenever it
  starts, so a change made there shows in the app instead of being overwritten the next time
  the game's settings are saved.

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Rebuild your games.** Games are compiled on your computer, so the fixes reach them only
   when they're built again. The launcher marks the games an older version built as
   *Rebuild needed*: press *Rebuild* on each.
3. **Android:** install `typex2-android.apk` over the old app, then export the **game packs**
   again (or the **RetroArch core**, then reinstall it in RetroArch: *Load Core → Install or
   Restore a Core*) and use *Send to device*.

No game files are included: you need your own copy of each game.
