# typex2-recomp 0.7.4

Building games on Windows with LLVM already installed, and a log of slow frames.

What's new:

- **Windows: no more "unsupported option '-fPIC'".** If LLVM's own clang was installed on your
  PC and the launcher's clang wasn't downloaded, building a game failed with that error
  ([#8](https://github.com/PabloVSouza/typex2-recomp/issues/8)). That clang can't build games
  for the player; the launcher now says so and points you to Settings → Tools, where
  *LLVM clang* downloads the one it needs.
- **Slow frames in the log (Vulkan).** Adding `X2_PACELOG=30` under a game's Environment
  logs every frame that takes over 30 ms (at most one line a second), with how long it waited
  for the GPU and where the rest went. If a game slows down for you, a log made this way
  helps find out why.

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Rebuild your games.** Games are compiled on your computer, so the fixes reach them only
   when they're built again. The launcher marks the games an older version built as
   *Rebuild needed*: press *Rebuild* on each.
3. **Android:** install `typex2-android.apk` over the old app, then export the **game packs**
   again (or the **RetroArch core**, then reinstall it in RetroArch: *Load Core → Install or
   Restore a Core*) and use *Send to device*.

No game files are included: you need your own copy of each game.
