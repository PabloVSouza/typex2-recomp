# typex2-recomp 0.7.6

Android exports work on computers without git.

What's new:

- **Android exports without git.** Exporting game packs or the RetroArch core for Android
  failed with "Configuring failed ... FetchContent" on computers without git, which is most
  Windows PCs: two libraries the build downloads (glslang, SDL) were fetched with git. They
  now come as release archives, checked against their SHA-256, so nothing besides the
  launcher's own tools is needed.

## Known issues

See [Known issues](https://github.com/PabloVSouza/typex2-recomp/blob/main/docs/Known-Issues.md).

## Install or update

1. **Update the launcher on your computer:** download it below (`.dmg` for macOS on Apple
   Silicon, `.AppImage` or `.deb` for Linux, `.msi` or setup `.exe` for Windows) and install it
   over the old one. Your library and settings stay.
2. **Export again** if an Android export failed before. The games themselves didn't change;
   if the launcher marks one *Rebuild needed*, press *Rebuild*.
3. **Android:** the app didn't change. Packs and the core exported with 0.7.5 keep working.

No game files are included: you need your own copy of each game.
